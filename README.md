# problem-solving

> 프로그래머스에서 제공하는 코딩 테스트 문제를 해결하고, 문제별 풀이 코드와 학습 과정을 기록하는 저장소입니다.

## Repository Purpose

본 저장소는 다음의 목적을 가지고 운영합니다.

- 프로그래머스 코딩 테스트 문제 풀이 기록
- 오답 문제 재풀이 및 풀이 개선 과정 관리
- `PCCP` & `PCSQL` 및 기업 코딩 테스트 대비

## Platform

- **Programmers (프로그래머스)**
- **Language:** `Python 3`, `SQL`

문제는 아래 URL 뒤에 문제 번호를 추가하여 확인 가능합니다.

```url
https://school.programmers.co.kr/learn/courses/30/lessons/{문제번호}
```

## Commit Convention

```text
[prgms] Lv.{난이도} {문제명} ({문제번호})
```

예시:

```text
[prgms] 완주하지 못한 선수 (42576)
```

## Notes
- 공개된 프로그래머스 연습문제만 기록합니다.
- 정답 코드만 저장하기보다 문제 접근 방식과 개선 과정을 주석으로 함께 관리합니다.
- 문제 원본 전체는 저장하지 않고 공식 문제 링크로 대체합니다.
- 기업 코딩 테스트 및 비공개 문제는 기록하거나 공유하지 않습니다.
